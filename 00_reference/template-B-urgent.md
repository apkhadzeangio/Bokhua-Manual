> **ფორმატის კვოტა:** 1 ჯიბის გვერდი (100×180 მმ) = ~250 სიტყვა (±12%). Markdown-ცხრილები: **მაქსიმუმ 3–4 სვეტი** (<=12–15 სიტყვა უჯრაში).

> ## [ქართული აკადემიური სათაური]
> *[English Academic Title]*
> **საყრდენი გაიდლაინები:** [მაგ., ESVS 2024, SVS 2023, ESVS 2020] | **დროის კრიტიკული ლიმიტი:** [ოქროს ფანჯარა / Door-to-Intervention სამიზნე]

### 1. პირველი 60 წამისა და „ოქროს საათის“ სამოქმედო ალგორითმი *(~15% მოცულობის)*
დროში მკაცრად გაწერილი ტექსტური სამოქმედო ნაკადი შესავალი მსჯელობის გარეშე:
- **`0–60 წმ` (უშუალო სიცოცხლის გადარჩენა):** აქტიური გარეგანი სისხლდენის კონტროლი (პირდაპირი ზეწოლა / პროქსიმალური ლახტი / ფოლის კათეტერით ტამპონადა ღრმა კისრის/ლავიწქვეშა ჭრილობაში), სასუნთქი გზები, 2 მსხვილკალიბრიანი ვენური ხაზი (`14–16G`).
- **`1–15 წთ` (ფიზიოლოგიური სტაბილიზაცია პათოლოგიის მიხედვით):**
  - *ჰემორაგიული შოკი / გასკდომა (`rAAA`, ტრავმა):* დასაშვები ჰიპოტენზია (`SBP 70–90 მმ ვწყ. სვ.`, შენარჩუნებული ცნობიერება), კრისტალოიდების შეზღუდვა, მასიური ტრანსფუზიის პროტოკოლი (`MTP 1:1:1` — `pRBC : FFP : თრომბოკონცენტრატი`), ტრანექსამის მჟავა (`TXA 1 გ ი/ვ` 10 წთ-ში ტრავმისას) `[ESVS 2024: I-B]`.
  - *მწვავე აორტის სინდრომი (`TBAD`):* მყისიერი ანტიიმპულსური თერაპია (`ი/ვ ესმოლოლი/ლაბეტალოლი` -> `HR <=60/წთ`, `SBP 100–120 მმ ვწყ. სვ.`) `[ACC/AHA 2022: 1-B]`.
  - *მწვავე არტერიული ოკლუზია (`ALI` / მეზენტერული იშემია):* დაუყოვნებელი `UFH 5,000 ერთ` (ან `80 ერთ/კგ`) ი/ვ ბოლუსი დიაგნოსტიკის დასრულებამდე `[ESVS 2020: I-C]`.
- **`15–60 წთ` („ოქროს საათის“ გადაწყვეტილება):** ჰიბრიდული საოპერაციოს მობილიზაცია, ურგენტული `CTA` მხოლოდ ჰემოდინამიკურად საკმარისად სტაბილურ პაციენტში, ან პირდაპირი გადაყვანა საოპერაციო მაგიდაზე.

### 2. „წითელი ალმები“ (Red Flags) და მყისიერი ტრიაჟი *(~15% მოცულობის)*
- **სარწმუნო (Hard Signs) vs სავარაუდო (Soft Signs) ნიშნები / იშემიის გრადაცია:** პულსირებადი სისხლდენა, მზარდი ჰემატომა, პულსის გაქრობა, ხმაური/თრთოლვა (`thrill/bruit`), დაზიანებული კიდურის ინდექსი (`IEI <0.90`), ან კიდურის მწვავე იშემიის `Rutherford I / IIa / IIb / III` კლასიფიკაცია (სენსორული და მოტორული დეფიციტი, დოპლერის არტერიული/ვენური სიგნალი).
- **3-სვეტიანი მყისიერი ტრიაჟის ცხრილი:**

| კლინიკური სტატუსი | პირდაპირი მარშრუტი | სამიზნე დრო / აკრძალვა |
| :--- | :--- | :--- |
| არასტაბილური / Hard Signs / `IIb` | პირდაპირ საოპერაციოში (ჰიბრიდული) | `<15–30 წთ`; `CTA`-ზე დაყოვნება აკრძალულია |
| სტაბილური / Soft Signs / `IIa` | სწრაფი `CTA` -> ღია ან ენდოვასკულური | `<60–90 წთ` |
| შეუქცევადი (`Rutherford III` / მანგლირებული) | პირველადი ამპუტაცია / Damage Control | რეპერფუზია აკრძალულია `[ESVS 2020: III-C (Harm)]` |

### 3. პროქსიმალური კონტროლი, Damage Control და დროებითი შუნტირება *(~20% მოცულობის)*
- **`Prep & Drape Awake` პროტოკოლი:** ნიკაპიდან მუხლებამდე (ან ტერფებამდე) სტერილური დამუშავება და ქირურგიული ბრიგადის სრული მზადყოფნა **ინტუბაციის/მიორელაქსაციის დაწყებამდე**, რათა თავიდან ავიცილოთ ტამპონადის მოხსნით გამოწვეული კოლაფსი.
- **უსწრაფესი პროქსიმალური კონტროლი:** ანატომიური გზა ღია სისხლძარღვოვანი გადაკეტვისთვის (მაგ., სუპრაცელიაკური აორტის გადაკეტვა მცირე ბადექონის გავლით, სტერნოტომია/თორაკოტომია, რეტროპერიტონეული კონტროლი) **ან** რესუსციტაციული აორტის ენდოვასკულური ბალონური ოკლუზია (`REBOA` — ზონა I დიაფრაგმის ზემოთ vs ზონა III აორტის ბიფურკაციის ზემოთ; ინფლაციის მკაცრი დროითი ლიმიტი).
- **Damage Control Vascular Surgery (`DCVS`):** „სასიკვდილო ტრიადის“ (`pH <7.20`, ტემპერატურა `<34°C`, `INR >1.5`) დროს — რომელი სისხლძარღვების ლიგირებაა დასაშვები და რომელთა არა; დროებითი შიდასისხლძარღვოვანი შუნტირების (`TIVS` — `Argyle` / `Pruitt-Inahara` / საინფუზიო მილი) ჩაყენებისა და ფიქსაციის ზუსტი პროტოკოლი.

### 4. დეფინიტური ქირურგიული / ენდოვასკულური რეკონსტრუქცია და Bailout *(~30% მოცულობის)*
- **ურგენტული ენდოვასკულური რეკონსტრუქცია:** ჰიპოვოლემიით გამოწვეული ვაზოსპაზმის კომპენსაცია (`20–30%` oversizing `rEVAR`/ტრავმულ აორტაში vs `0–10%` მწვავე დისექციაში სტენტგრაფტით ინდუცირებული ახალი ნახეთქის `SINE` თავიდან ასაცილებლად), ბიფურკაციული vs აორტო-უნიილიაკური (`AUI`) კონფიგურაცია + ბარძაყ-ბარძაყის ჯვარედინი შუნტირება, დაფარული სტენტგრაფტები.
- **ღია რეკონსტრუქცია ურგენტულ და კონტამინირებულ ველში:** დევიტალიზებული კიდეების ეკონომიური აკვეთა, ფოგარტის ბალონური თრომბექტომია (`2Fr–5Fr`) დისტალურ აუზში, რეგიონული ჰეპარინირებული ხსნარის შეყვანა (`50 ერთ/მლ`), აუტოლოგიური რევერსირებული დიდი საჩინო ვენა (`GSV` კონტრალატერალური საღი კიდურიდან!), ნაფლეთით პლასტიკა ან ექსტრაანატომიური გზა.
- **ქსოვილოვანი დაფარვა და ინტრაოპერაციული Bailout:** ანასტომოზის აუცილებელი დაფარვა სიცოცხლისუნარიანი ქსოვილით (თერძის კუნთის ნაფლეთი, დიდი ბადექონის ნაფლეთი); აორტო-ოკლუზიური ბალონის შენარჩუნება, I ტიპის ენდოჟონვის, ნაკადის არარსებობის (`no-reflow`) და კოაგულოპათიური სისხლდენის ინტრაოპერაციული მართვა.

### 5. რეპერფუზიის სინდრომი, კომპარტმენტ-დეკომპრესია და ICU ფაზა *(~15% მოცულობის)*
- **რეპერფუზიული და მეტაბოლურ-რენული დაცვა:** ჰიპერკალიემიის, მეტაბოლური აციდოზისა და მიოგლობინურიული თირკმლის მწვავე დაზიანების (რაბდომიოლიზი, `CK >5,000 ერთ/ლ`) აგრესიული მართვა გადაკეტვის მოხსნამდე და მოხსნისთანავე.
- **წვივის ფასციოტომია:** პროფილაქტიკური (იშემია `>4–6 სთ`, კომბინირებული არტერიულ-ვენური ტრავმა) და სამკურნალო ჩვენებები — კომპარტმენტის წნევა `ICP >=30 მმ ვწყ. სვ.` ან დიასტოლურ წნევასთან სხვაობა `Delta P <=30 მმ ვწყ. სვ.`; სრული 2-განაკვეთიანი 4-კომპარტმენტის დეკომპრესიის ანატომიური ორიენტირები (ზედაპირული ხედვის ნერვისა და დიდი საჩინო ვენის დაცვით).
- **მუცლის კომპარტმენტ-სინდრომი (`ACS`) და `Second-Look`:** შარდის ბუშტის წნევის მონიტორინგი (`IAP >20 მმ ვწყ. სვ.` + ახალი ორგანული დისფუნქცია -> დეკომპრესიული ლაპაროსტომია ვაკუუმ-სისტემით `[ESVS 2024: I-B]`) და დაგეგმილი `second-look` ლაპაროტომია/რევიზია `24–48 სთ`-ში.

> **🔴 გადარჩენის კლინიკური წესები (Red-Page Survival Rules)** *(~5% მოცულობის)*
> - ⚡ **სავალდებულო წესი 1:** [კრიტიკული, სიცოცხლის გადამრჩენი იმპერატივი ზუსტი ციფრებით/თანმიმდევრობით].
> - ⚡ **სავალდებულო წესი 2:** [საოპერაციო ტექნიკური ან დროითი უპირობო მოთხოვნა].
> - ⛔ **Never-Do 1:** [სასიკვდილო/კიდურის დამკარგველი შეცდომა, რომელიც კატეგორიულად იკრძალება].
> - ⛔ **Never-Do 2:** [მეორე კატეგორიული აკრძალვა + გაიდლაინის `III (Harm)` ლოგიკა].
