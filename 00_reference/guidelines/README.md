# ოფიციალური გაიდლაინების საცავი (`00_reference/guidelines/`)

ეს საქაღალდე განკუთვნილია **Bokhua Manual of Vascular Surgery**-ის საყრდენი კლინიკური გაიდლაინების PDF ფაილებისთვის, რომლებსაც იყენებენ `/draft-chapter` და `/audit-chapter` ავტომატიზებული პროცესები.

## 1. ფაილების სახელდების სტანდარტი
განათავსეთ ოფიციალური PDF დოკუმენტები ერთიანი, მანქანურად კითხვადი სახელდებით:
`[Society]-[Year]-[Topic-Slug].pdf`

### რეკომენდებული სახელდების ნიმუშები:
- `ESVS-2024-AAA.pdf` — მუცლის აორტა-თეძოს არტერიების ანევრიზმების მართვა
- `ESVS-2024-PAD.pdf` — ქვემო კიდურების პერიფერიული არტერიული დაავადება (ასიმპტომური და კლაუდიკაცია)
- `ESVS-2023-Carotid-Vertebral.pdf` — ათეროსკლეროზული საძილე და ხერხემლის არტერიების დაავადება
- `ESVS-2023-Antithrombotic.pdf` — ანტითრომბოზული თერაპია სისხლძარღვოვან პათოლოგიებში
- `ESVS-2022-CVD.pdf` — ქრონიკული ვენური დაავადების მართვა
- `ESVS-2021-Venous-Thrombosis.pdf` — ვენური თრომბოზის მართვა
- `ESVS-2020-ALI.pdf` — კიდურის მწვავე იშემია
- `ESVS-2020-VGEI.pdf` — სისხლძარღვოვანი პროთეზისა და ენდოგრაფტის ინფექცია
- `ESVS-2018-Vascular-Access.pdf` — ჰემოდიალიზის სისხლძარღვოვანი წვდომა
- `ESVS-2017-Mesenteric.pdf` — მეზენტერული არტერიებისა და ვენების დაავადებები
- `GVG-2019-CLTI.pdf` — Global Vascular Guidelines კრიტიკული იშემიის (CLTI) მართვაზე
- `SVS-2023-Vascular-Trauma.pdf` / `ESVS-2025-Vascular-Trauma.pdf` — სისხლძარღვოვანი ტრავმა
- `ACC-AHA-2022-Aortic-Disease.pdf` — გულმკერდისა და მუცლის აორტის პათოლოგიები
- `ESC-2024-PAOD.pdf` — პერიფერიული არტერიული და აორტის დაავადებები
- `ESC-2022-Noncardiac-Surgery.pdf` — არაკარდიული ქირურგიის კარდიოვასკულური შეფასება
