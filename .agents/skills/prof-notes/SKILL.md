# `/prof-notes` — პროფესორის კლინიკური კორექტივების ინტეგრაცია

გამოიყენება მაშინ, როდესაც პროფესორი (ან მთავარი რედაქტორი) აწვდის პრაქტიკულ ქირურგიულ შენიშვნებს, კლინიკურ ნიუანსებს ან ინსტიტუციურ გამოცდილებას Bokhua-Manual-ის კონკრეტული თავისთვის (`ch-NN.md`).

## შესრულების მკაცრი პროტოკოლი

1. **კონტექსტის წაკითხვა:**
   - წაიკითხე სამიზნე `manuscript/XX-.../ch-NN.md`, შესაბამისი `audits/ch-NN-audit.md` (თუ უკვე არსებობს) და `00_reference/glossary-vascqbank.md`.
   - გააანალიზე პროფესორის მიერ მოწოდებული თითოეული კლინიკური შენიშვნა, ტექნიკური დეტალი ან ტაქტიკური აქცენტი.

2. **ორგანული ორდონიანი ინტეგრაცია:**
   - **ძირითად ტექსტში (`§§3–6`):** ჩააშენე პროფესორის პრაქტიკული კორექტივები უშუალოდ შესაბამის ოპერაციულ ნაბიჯებში (მაგ., განაკვეთის მოდიფიკაცია, სისხლძარღვის გამოყოფის სიბრტყე, დამჭერის დადების ნიუანსი, კონდუიტის/ნაფლეთის არჩევანი, ინტრაოპერაციული bailout).
   - **საფირმო დასკვნით ბლოკში:** ყველაზე ღირებული კლინიკური სიბრძნე და საფრთხის პრევენცია გამოკვეთე დასკვნით ბლოკ-ციტატაში:
     - სტანდარტულ თავებში: `> **ბოხუას კლინიკური მარგალიტები (Pearls & Pitfalls)**` (`✓` და `⚠`);
     - ურგენტულ თავებში (კარი IV): `> **🔴 გადარჩენის კლინიკური წესები (Red-Page Survival Rules)**` (`⚡` და `⛔`).

3. **კვოტის ბალანსირება და ენობრივი ფილტრაცია:**
   - **გვერდების კვოტის ხელშეუხებლობა:** ახალი მასალის დამატებისას შეამჭიდროვე მეორეხარისხოვანი ფრაზები ისე, რომ თავის ჯამური სიტყვების რაოდენობა მკაცრად დარჩეს პასპორტით განსაზღვრულ `გვერდები × 250` ბიუჯეტის ფარგლებში და არცერთი ცხრილი არ გასცდეს 4 სვეტს.
   - **ანტი-ჟარგონის ფილტრი:** თუ პროფესორის ზეპირ ან სწრაფ ჩანაწერში გამოყენებული იყო საოპერაციო ჟარგონი/კალკი (მაგ., *პატჩი, შიზი, კლამპი, ილიაკური, რუპტურა, ტურნიკეტი*), აუცილებლად გარდაქმენი იგი აკადემიურ VascQBank სტანდარტად კლინიკური აზრის 100%-იანი შენარჩუნებით.

4. **სავალდებულო ტექნიკური ვერიფიკაცია:**
   - ტერმინალში გაუშვი:
     ```bash
     python3 scripts/check_chapter.py <ფაილის_მისამართი> --part full
     ```
   - ნებისმიერი `[ERROR]`-ის ან კვოტური გადახრის შემთხვევაში შეასწორე ტექსტი `exit code 0`-ის მიღწევამდე.

5. **ფინალური დასტური (`Prof Sign-off`):**
   - განაახლე `PROGRESS.md` — შესაბამისი თავის `პროფესორის დასტური` სვეტში ჩაწერე `✅ Prof Sign-off` (სტამბაში გასაშვებად მზა სტატუსი).
