# Workflow: `/draft-chapter` — თავის აკადემიური გენერაცია

გამოიყენება კონკრეტული თავის ან მისი ნაწილის დასაწერად (მაგ.: `/draft-chapter 1 part 1`, `/draft-chapter 1 part 2`, `/draft-chapter 7 full`).

## შესრულების მკაცრი პროტოკოლი

1. **არგუმენტების პარსინგი და რეჟიმის შემოწმება:**
   - განსაზღვრე თავის ნომერი `NN` (`01`–`75`, ორნიშნა ფორმატით: `ch-01.md` ... `ch-75.md`) და მოთხოვნილი ნაწილი (`part 1`, `part 2` ან `full`).
   - **2-პრომპტიანი კანონის კონტროლი:** მხოლოდ 4-გვერდიანი თავებისთვის (`თავი 7` და `თავი 14`) არის ნებადართული `full` რეჟიმი ერთ გენერაციაში. ყველა 5+ გვერდიანი თავისთვის (`[2 პრომპტი]`) სავალდებულოა ორეტაპიანი წერა (`part 1` -> ჩერდება ზუსტად `### 3.`-ის ბოლოს; `part 2` -> აგრძელებს `### 4.`-დან დასკვნით ბლოკამდე).

2. **საყრდენი კონტექსტის წაკითხვა:**
   - წაიკითხე `.agent/rules/editorial-constitution.md` (უცვლელი წესები).
   - წაიკითხე `00_reference/toc-master.md` — დაადგინე სამიზნე კარი, საქაღალდე, გვერდების ზუსტი კვოტა, სიტყვების ბიუჯეტი (`გვერდები × 250`) და თავის ქვეთემები.
   - წაიკითხე `00_reference/glossary-vascqbank.md` — ქართული ნომენკლატურის 8 კანონისა და ანტი-ჟარგონის დასაცავად.
   - წაიკითხე შესაბამისი Master Template:
     - თუ `23 <= NN <= 31` (კარი IV — წითელი გვერდები): `00_reference/template-B-urgent.md`.
     - ყველა სხვა თავისთვის (`1–22`, `32–75`): `00_reference/template-A-standard.md` (კარი I, II, III, XI სექციური ადაპტაციის გათვალისწინებით).

3. **გაიდლაინების გადამოწმება:**
   - შეამოწმე `00_reference/guidelines/` საქაღალდე შესაბამისი ოფიციალური გაიდლაინების PDF ფაილების არსებობაზე (`ESVS`, `SVS`, `ACC/AHA`, `ESC`, `GVG`). არსებობის შემთხვევაში დაეყრდენი პირველწყაროს ზუსტ ციფრებსა და რეკომენდაციის კლასებს.

4. **სამიზნე ფაილის განსაზღვრა (`manuscript/XX-.../ch-NN.md`):**
   - `01–07` -> `manuscript/01-perioperative/ch-NN.md`
   - `08–15` -> `manuscript/02-endovascular-basics/ch-NN.md`
   - `16–22` -> `manuscript/03-open-techniques-exposures/ch-NN.md`
   - `23–31` -> `manuscript/04-urgent-trauma-red-pages/ch-NN.md`
   - `32–38` -> `manuscript/05-supraaortic-upper-limb/ch-NN.md`
   - `39–47` -> `manuscript/06-thoracic-abdominal-aorta-iliac/ch-NN.md`
   - `48–55` -> `manuscript/07-lower-extremity-pad-clti/ch-NN.md`
   - `56–59` -> `manuscript/08-visceral-renal/ch-NN.md`
   - `60–65` -> `manuscript/09-venous-lymphatic/ch-NN.md`
   - `66–71` -> `manuscript/10-dialysis-amputation-vgei/ch-NN.md`
   - `72–75` -> `manuscript/11-formulary-reference-index/ch-NN.md`

5. **ტექსტის აკადემიური დრაფტინგი:**
   - დაიწყე პირველივე წინადადება კლინიკური/ქირურგიული არსით — ყოველგვარი შესავალი ფრაზების გარეშე.
   - ყველა ცხრილი ააგე **მაქსიმუმ 3 ან 4 სვეტით** (<=12–15 სიტყვა უჯრაში).
   - საჭირო ტოპოგრაფიულ, ანატომიურ და ტექნიკურ ადგილებში ჩასვი სტანდარტული ილუსტრაციის ბლოკი (`00_reference/figures-spec.md`-ის ფორმატით: `> **[სურ. NN.X | 0.5 გვ. | assets/figures/.../fig-NN-0X.svg]**` + სათაური, ნომერაციული ლეგენდა და დავალება ილუსტრატორისთვის). ილუსტრაციები ემატება ტექსტური კვოტის ზემოდან (Additive მოდელი).
   - ყველა კლინიკურ ზღვარსა და დოზას მიუთითე გაიდლაინის კოდი (`[ESVS 2024: I-A]` და ა.შ.) და ზუსტი საოპერაციო პარამეტრები (`მმ`, `%`, `PSV`, `ACT`, `Fr`, ძაფის ზომა).
   - **თუ მოთხოვნილია `part 1`:** შექმენი `ch-NN.md` პასპორტით და ქვეთავებით `### 1.`–`### 3.` (სრული სიტყვების ბიუჯეტის ~45–52%) და **გაჩერდი ზუსტად §3-ის ბოლოს**.
   - **თუ მოთხოვნილია `part 2`:** წაიკითხე უკვე არსებული `ch-NN.md` (`Part 1/2`), არ გაიმეორო §§1–3 და იმავე ფაილში დაამატე `### 4.`-დან დასკვნით ბლოკამდე (`ბოხუას კლინიკური მარგალიტები` ან `🔴 გადარჩენის კლინიკური წესები`).
   - **თუ მოთხოვნილია `full` (`თავი 7` ან `თავი 14`):** დაწერე თავი სრულად ერთ ფაილში.

6. **ავტომატური ტექნიკური ვალიდაცია (სავალდებულო):**
   - ტერმინალში გაუშვი:
     ```bash
     python3 scripts/check_chapter.py <ფაილის_მისამართი> --part <1|2|full>
     ```
   - თუ სკრიპტმა გამოიტანა ნებისმიერი `[ERROR]` ან კრიტიკული `[WARNING]` (აკრძალული ჟარგონი, 5+ სვეტიანი ცხრილი, სიტყვების კვოტის დარღვევა, გაიდლაინის კოდების ან დასკვნითი ბლოკის ნაკლებობა), დაუყოვნებლივ შეასწორე `ch-NN.md` და გაუშვი სკრიპტი ხელახლა, სანამ არ მიიღებ სუფთა შედეგს (`exit code 0`).

7. **პროგრესისა და ილუსტრაციების ასახვა:**
   - განაახლე `PROGRESS.md`-ში შესაბამისი თავის სტრიქონი (`✅` შესრულებულ `Part 1/2` ან `Part 2/2 (Full)` სვეტში სიტყვების რაოდენობის მითითებით).
   - თუ თავში დაემატა `[სურ. NN.X ...]` ბლოკები, დაარეგისტრირე ისინი `FIGURES.md`-ში.
