# Workflow: `/audit-chapter` — დამოუკიდებელი აკადემიური რეცენზირება

გამოიყენება დასრულებულ `manuscript/XX-.../ch-NN.md` ფაილზე როგორც მკაცრი, უკომპრომისო სისხლძარღვთა ქირურგი რეცენზენტი და საგამომცემლო კონტროლიორი.

## აუდიტის 4-საფეხურიანი პროტოკოლი

### ნაბიჯი 1. ავტომატიზებული ტექნიკური, ტერმინოლოგიური და კაბადონის სკანირება
- იპოვე შესაბამისი `manuscript/XX-.../ch-NN.md` ფაილი და ტერმინალში გაუშვი:
  ```bash
  python3 scripts/check_chapter.py <ფაილის_მისამართი> --part full
  ```
- აღრიცხე ყველა გამოვლენილი ტექნიკური, კვოტური, ცხრილური (`>4` სვეტი, გადატვირთული უჯრები) და ენობრივი ხარვეზი.

### ნაბიჯი 2. რიცხვითი მაჩვენებლებისა და გაიდლაინების კოდების ფაქტ-ჩეკინგი
- წაიკითხე თავი სტრიქონ-სტრიქონ და გადაამოწმე **ყველა** რაოდენობრივი პარამეტრი `00_reference/guidelines/` საქაღალდეში არსებულ PDF-ებთან (ხოლო თუ შესაბამისი PDF ლოკალურად არ დევს — ვებ-ძიებით ოფიციალურ `ESVS`, `SVS`, `ACC/AHA`, `ESC`, `GVG` წყაროებთან):
  - ანატომიური და ჩარევის ზღვრები (`მმ`, `%`, სქესობრივი და რისკ-დიფერენციაცია);
  - დუპლექსსკანირების კრიტერიუმები (`PSV`, `EDV`, `PSVR`, `ABI`, `TBI`, `TcPO2`);
  - ინტრაოპერაციული პარამეტრები (`UFH` დოზა, `ACT` წამებში, ინტროდიუსერის `Fr`, გამტარები, ბალონის `atm`, `Oversizing %`, ძაფის ზომა);
  - ანტითრომბოზული რეჟიმები (`SAPT`, `DAPT`, `DPI`, `DOAC` დოზები და ხანგრძლივობა) და მეთვალყურეობის ვადები;
  - თითოეული `[Society Year: Class-Level]` კოდის რეალური შესაბამისობა გაიდლაინის კლასთან და მტკიცებულების დონესთან (მათ შორის `III-C (Harm)` უკუჩვენებები).

### ნაბიჯი 3. ქირურგიული და კლინიკური სისრულის ექსპერტიზა
- შეამოწმე, შეიცავს თუ არა თავი პრაქტიკოსი ქირურგისთვის აუცილებელ ყველა საოპერაციო დეტალს:
  - ზუსტი ანატომიური ორიენტირები და ფასციური შრეები;
  - კრიტიკული ნერვების, შარდსაწვეთისა და ვენური სტრუქტურების იდენტიფიკაცია და დაცვა;
  - სისხლძარღვოვანი დამჭერებით გადაკეტვისა და ნაკადის აღდგენის (გამორეცხვის) უსაფრთხო თანმიმდევრობა;
  - რეალისტური ინტრაოპერაციული სამაშველო მანევრები (`bailout`) და აბსოლუტური უკუჩვენებები;
  - VascQBank ტერმინოლოგიური სისუფთავე (`00_reference/glossary-vascqbank.md`-ის მიხედვით, მათ შორის ფარული კალკებიც, რომლებიც შესაძლოა regex-ს გაექცეს: `წვდომა` vs `მიდგომა` vs `გამოყოფა`, `დისექციის` არამიზნობრივი გამოყენება და სხვ.).

### ნაბიჯი 4. აუდიტის ოქმის შექმნა, კორექტირება და რე-ვალიდაცია
1. შექმენი დეტალური რეცენზიის ოქმი ფაილში `audits/ch-NN-audit.md` შემდეგი სტრუქტურით:
   - **აუდიტის შეჯამება:** თარიღი, შემოწმებული გაიდლაინები, გამოვლენილი ხარვეზების რაოდენობა კატეგორიების მიხედვით;
   - **ცვლილებათა ჟურნალი (ცხრილი <=4 სვეტი):** `ქვეთავი | რა იყო უზუსტო / ხარვეზი | რით შეიცვალა (სწორი ვერსია) | წყარო / დასაბუთება`;
   - **დასკვნა:** თავის მზადყოფნის სტატუსი პროფესორის ფინალური განხილვისთვის.
2. შეიტანე ყველა შესწორება უშუალოდ `manuscript/XX-.../ch-NN.md` ფაილში გვერდების კვოტის დარღვევის გარეშე.
3. ხელახლა გაუშვი ტერმინალში:
   ```bash
   python3 scripts/check_chapter.py <ფაილის_მისამართი> --part full
   ```
   და დარწმუნდი, რომ შედეგი არის **0 შეცდომა (`exit code 0`)**.
4. განაახლე `PROGRESS.md` — მონიშნე `კლინიკური აუდიტი` სვეტში `✅ (audits/ch-NN-audit.md)`.
